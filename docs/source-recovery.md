# Source engine and playback recovery

The production entry point uses `src/source-engine.js`, adapted from the standalone algorithms in the Downloads workspace. Old provider parsers remain for legacy fixtures but are no longer the production discovery or renewal path. The copied code was authored independently; upstream repositories served as primary research references, not copied implementation.

Discovery visits AnimeUnity then AnimeWorld, rejects incomplete searches, retains separate dubbed editions, and searches up to twelve supplied title aliases. Query shortening broadens retrieval only; acceptance still requires an exact known title/alias with consistent catalog IDs or independent format/year/count evidence. Decimal, range and opaque episode labels remain diagnostic results because the current library cannot represent them as integer keys. They are never rounded or expanded. One-shot units still pass through the existing media-part model; no membership or category rewrite is performed.

A provider's OVA/MOVIE presentation category can differ for a theatrical OVA. The adapter reconciles only that category when MAL ID, exact full title, year and independently reported single-unit count all match and there is no other conflict. This permits AnimeWorld's Movie entry for Memory Snow to support the canonical OVA without changing the library format. A shared AniList ID, similar name or equal file count alone is insufficient.

Automatic sources retain stable provider work and episode IDs and distinct HLS/file IDs. Signed URLs are device-local. A playback proxy validates every upstream request and redirect, uses the correct cookie jar and Referer, rewrites HLS segment/key/map URLs, and is closed with its own player session. The selected HLS variant is the highest compatible declared resolution. This is not a subjective quality comparison or proof that a declared resolution is native.

After 5 seconds without observed media-time movement, a loaded remote source is stopped; the watchdog polls every second. The same threshold applies during seeking; user pause and zero speed suppress the watchdog. IPC responsiveness alone does not count as playback progress. Network errors and premature EOF use the same recovery path. EOF within 1% or three seconds of the end is accepted, so a tiny missing tail cannot be ruled out.

Stalled playback immediately tries another eligible source attached to the same UUID, preferring another provider. A network error can first renew an automatic source once when playback was established. Each source is attempted at most once plus its single network-error renewal. The newest observed time is carried explicitly, even for an already-watched item. Stop, delete, account change or a new Play invalidates pending work and aborts proxy requests. Known audio language is preserved; a different language uses the existing explicit fallback dialog.

A replacement must report a duration within the larger of three seconds or 1% of the prior duration, and must start within three seconds of the requested time. Incompatible sources are rejected without resetting the saved checkpoint or marking the item watched. Similar duration alone does not prove identical edits, advertisements or synchronized subtitles; frame-exact alignment across unrelated encodes remains unverified.

The two Re:Zero films have separate provider entries: Memory Snow (2018, MAL 36286) and The Frozen Bond/Hyouketsu no Kizuna (2019, MAL 38414). For the exact AniList 100049 OVA aggregate with two canonical episodes, discovery searches each known component independently and maps them to episodes 1 and 2 only after validating their title, year, unit count and MAL identity. It does not use the shared AniList ID alone, alter the aggregate's format, or create/merge library works. Other bundles still require explicit component selection.

Previously attached automatic sources inside that specific aggregate renew their named film by the original public work URL and episode ID, after validating the individual film's title/year/count/catalog evidence. Renewal preserves the canonical episode number separately from the provider episode number and never searches by title during playback.

No download UI, StreamingCommunity production adapter, full-film endurance certification, installer execution or remote publication is part of this change.
